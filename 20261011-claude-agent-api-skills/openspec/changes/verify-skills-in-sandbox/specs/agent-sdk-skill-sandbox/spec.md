# Spec Delta

## Purpose

Claude Agent SDK で、コマンド実行とファイル操作をすべて sandboxd 経由の tool に置き換えたとき、スキルの SKILL.md・参照ファイル・Python スクリプトがどこから読まれ、どこで実行されるかを観測して記録する。

## ADDED Requirements

### Requirement: 検証用スキル
システムは、検証用スキル `sandbox-probe` を持たなければならない(SHALL)。スキルは次の 3 つを含む。
- `SKILL.md`: 参照ファイルを読み、スクリプトを実行して結果を報告するよう指示する
- 参照ファイル: スキルの中にしかない合言葉を書いたもの
- Python スクリプト: 実行時のホスト名、マーカーファイルの内容、カレントディレクトリ、スクリプト自身の絶対パス、Python 実行ファイルのパスを出力するもの

合言葉とマーカーは、SKILL.md 本文やシステムプロンプトに含めてはならない(MUST)。ファイルを実際に読んだか、実行したかを区別するためである。

#### Scenario: スクリプトの単体実行
- **WHEN** スクリプトをホストとサンドボックスのそれぞれで直接実行する
- **THEN** マーカーの有無とホスト名で、どちらで実行したかが区別できる

### Requirement: tool をサンドボックスに閉じ込める
Agent SDK の実行では、組み込みのコマンド実行とファイル操作の tool(Bash、Read、Write、Edit、Glob、Grep)を無効にしなければならない(MUST)。代わりに sandboxd を呼ぶカスタム tool(コマンド実行、ファイル読み取り、ディレクトリ一覧)と、スキル機能だけを有効にする。ホストでコマンドが実行されていないことを、tool 呼び出しの記録で確認できなければならない(MUST)。

#### Scenario: ホスト側の tool が使われない
- **WHEN** スキルを使う依頼をエージェントに送る
- **THEN** 記録された tool 呼び出しは、スキル機能とサンドボックス用のカスタム tool だけである

### Requirement: スキルのファイルの所在の観測
システムは、次の各条件でエージェントを実行し、観測した内容を記録しなければならない(SHALL)。
- 条件 A: スキルはホストにだけ置き、サンドボックスにはコピーしない
- 条件 B: スキルのファイルをサンドボックスにコピーする
- 条件 C: コマンド実行だけサンドボックスにし、ホストのファイル読み取り(Read)は許可する。スキルはホストにだけ置く

記録する内容:
- スキル機能が返した内容(SKILL.md の本文、スキルのベースディレクトリとして示されたパス)
- 参照ファイルをどの tool で、どのパスとして読もうとしたか、その結果
- スクリプトをどのコマンドで実行しようとしたか、その結果(マーカー、ホスト名、パス)
- エージェントの最終応答

#### Scenario: コピーしない場合(条件 A)
- **WHEN** 条件 A でスキルを使う依頼を送る
- **THEN** スキル機能が示したパスと、サンドボックス内でそのパスが存在するかどうかが記録される。参照ファイルの読み取りとスクリプト実行の成否が記録される

#### Scenario: コピーした場合(条件 B)
- **WHEN** 条件 B でスキルを使う依頼を送る
- **THEN** スクリプトの出力にサンドボックスのマーカーが含まれ、応答が合言葉とマーカーの両方を述べていることが確認される。成功しない場合は、その理由が記録される

#### Scenario: 読み取りだけホストの場合(条件 C)
- **WHEN** 条件 C でスキルを使う依頼を送る
- **THEN** 参照ファイルがホストから読めたかどうかと、スクリプトがサンドボックスで実行できたかどうかが、それぞれ記録される

### Requirement: 実行条件の固定
Agent SDK の実行では、モデル `claude-haiku-5-5` を使い、1 回の実行の費用とターン数に上限を設けなければならない(MUST)。ユーザやプロジェクトの設定(`~/.claude` など)の影響を受けないよう、設定ディレクトリを実行ごとに分けなければならない(MUST)。

#### Scenario: 使用モデルの確認
- **WHEN** 実行結果を確認する
- **THEN** 実際に使われたモデル名が `claude-haiku-5-5` であることが記録されている
