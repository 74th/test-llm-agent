# background-task-continuation Specification

## Purpose

バックグラウンドで実行中の tool の完了を契機に、Claude Agent SDK のエージェントが追加の応答を返せるかを検証可能にする。

## Requirements

### Requirement: バックグラウンド実行を開始して先に返答できる
システムは、時間のかかる処理をバックグラウンドで開始し、完了を待たずに最初の返答を返せなければならない(MUST)。

#### Scenario: 即時の中間返答
- **WHEN** 数十秒かかるコマンドをバックグラウンドで実行するよう依頼する
- **THEN** コマンドの完了前に最初の ResultMessage が得られる

### Requirement: 待機中に次の対話を受け付けられる
システムは、バックグラウンド処理の実行中に、同じセッションで次のユーザ入力を処理できなければならない(SHALL)。

#### Scenario: 待機中の追加質問
- **WHEN** バックグラウンド処理の実行中に無関係な質問を送る
- **THEN** 処理の完了を待たずにその質問への応答が得られる

### Requirement: 完了を契機とした追加応答
システムは、バックグラウンド処理の完了を契機に、ユーザの新規入力なしでエージェントが追加の応答を生成できなければならない(MUST)。可否は検証により確定し、不可の場合は代替方式(完了通知を次ターンの入力として注入する等)の可否を記録する。

#### Scenario: 完了時の自動応答
- **WHEN** バックグラウンド処理が完了し、その出力に固有値が含まれる
- **THEN** 完了後に、その固有値に言及する追加のアシスタント応答が得られる

#### Scenario: 非対応の場合の記録
- **WHEN** SDK の標準機能だけでは完了契機の応答が得られない
- **THEN** 報告書に「非対応」と観測した挙動を記録し、完了通知を入力として注入する代替方式で同等の動作が可能かを併せて記録する
