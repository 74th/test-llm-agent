# Spec Delta

## Purpose

検証ハーネスの構成・実行手順・人間が事前に用意すべきもの・人間が目視で確認すべき項目を README に集約し、他者が同じ検証を再現できる状態にする。

## ADDED Requirements

### Requirement: README の構成説明

`README.md` は、この検証ハーネスの構成要素と、どこで何が実行されるのかを説明しなければならない（SHALL）。

#### Scenario: 責務の境界が書かれている

- **WHEN** README を読む
- **THEN** エージェントループは Anthropic 側、ツール実行は自前コンテナ側、MCP ツールの実行は Anthropic 側であることが明記されている

#### Scenario: ディレクトリ構成が書かれている

- **WHEN** README を読む
- **THEN** ワーカー・オーケストレータ・プロビジョニングスクリプト・skills・`mcp.json`・Terraform の各ディレクトリの役割が一覧できる

#### Scenario: 2 つの起動モードの違いが書かれている

- **WHEN** README を読む
- **THEN** モード A（常駐単一コンテナ）とモード B（セッション毎コンテナ）の違い、それぞれの起動コマンド、状態の持ち越しに関する差が説明されている

### Requirement: 人間が事前に設定すべき内容

README は、実行前に人間が用意しなければならない資格情報と設定を、手順として列挙しなければならない（SHALL）。

#### Scenario: 必要な資格情報が列挙されている

- **WHEN** README の事前設定の節を読む
- **THEN** Anthropic API キー、Console での environment key 発行、GitHub PAT の作成（必要なスコープを含む）、GCP サービスアカウントキーの取得が、それぞれ取得方法とともに列挙されている

#### Scenario: 事前に必要なツールが列挙されている

- **WHEN** README を読む
- **THEN** Docker・Terraform・Python のバージョン要件と、コンテナイメージに必要な前提（`/bin/bash` の存在など）が書かれている

#### Scenario: 秘密情報の置き場所が示されている

- **WHEN** README を読む
- **THEN** 各資格情報をどのファイル・環境変数に置くか、およびそれらをバージョン管理に含めないことが明記されている

### Requirement: 検証手順

README は、検証を最初から最後まで実行する手順を、順序付きで記載しなければならない（SHALL）。

#### Scenario: 手順が順番に実行できる

- **WHEN** README の検証手順に従って上から順に実行する
- **THEN** Terraform 適用 → プロビジョニング → モード A の検証 → モード B の検証 の順で完走でき、各手順に実行するコマンドが書かれている

#### Scenario: 各検証項目が手順と対応している

- **WHEN** README を読む
- **THEN** 「自前コンテナでの実行」「skills の認識」「MCP の認識」「モード A」「モード B のコンテナ起動終了イベント」「BigQuery アクセス」の 6 項目が、それぞれどの手順で確認されるかが対応付けられている

### Requirement: 人間が確認すべき内容

README は、自動では判定せず人間が目視で確認する項目を、期待される結果とともに列挙しなければならない（SHALL）。

#### Scenario: 目視確認項目に期待結果が併記されている

- **WHEN** README の確認項目の節を読む
- **THEN** 各項目に「どこを見るか」と「何が見えていれば合格か」が併記されている

#### Scenario: ライフサイクルログの確認方法が示されている

- **WHEN** README を読む
- **THEN** ライフサイクルログのパス、1 レコードの例、ターン数と起動終了イベント数の対応をどう確認するかが書かれている

#### Scenario: 片付け方法が示されている

- **WHEN** README を読む
- **THEN** 検証後に残るリソース（Agent・Environment・vault・skill・Terraform 資源・発行したキー）と、その片付け方が書かれており、アーカイブが取り消せないことが注意として明記されている
