# self-hosted-tool-execution Specification

## Purpose

OpenAI Agents API のエージェントが要求したファイル操作とコマンドが自前の実行環境で行われたことを、再現可能な証拠とともに確認する。

## Requirements

### Requirement: 自前コンテナでのツール実行を証明する
検証ハーネスは self-hosted セッションを自前コンテナの executor に接続し、コンテナ固有の値をエージェントのツール操作で読み取れるものとしなければならない (SHALL)。検証結果は回答だけでなく、実行ログまたはコンテナ内ファイルと照合できなければならない (SHALL)。

#### Scenario: コンテナ固有マーカーを読む
- **WHEN** 検証者がコンテナイメージに固有マーカーを設定し、エージェントへマーカーの読み取りを指示する
- **THEN** エージェントの出力とツール実行記録のマーカー値が、起動したコンテナに設定した値と一致する

### Requirement: 接続と実行の失敗を区別する
検証ハーネスは executor の接続失敗と、接続後のツール実行失敗を異なる結果として報告しなければならない (SHALL)。成功の判定にはターンの完了状態と対象ツールの結果の両方を用いなければならない (MUST)。

#### Scenario: executor が接続できない
- **WHEN** executor が指定時間内にセッションへ接続できない
- **THEN** 検証結果は接続失敗として記録され、ツール実行成功とは判定されない

#### Scenario: ツールが失敗する
- **WHEN** セッションのターンは完了したが対象ツールが失敗する
- **THEN** 検証結果はツール失敗として記録され、合格とは判定されない

### Requirement: 資格情報を分離する
検証ハーネスはアプリ用 API キーをコンテナへ渡してはならない (MUST NOT)。executor 用資格情報の値をイメージ、ソース、成果物、ライフサイクルログに記録してはならない (MUST NOT)。

#### Scenario: コンテナ構成を確認する
- **WHEN** 検証者がコンテナの環境変数名、イメージ、出力ログを調べる
- **THEN** アプリ用 API キーはコンテナに存在せず、executor 用キーの値はイメージとログに含まれず、executor には接続に必要な制限付きキーのみが与えられる
